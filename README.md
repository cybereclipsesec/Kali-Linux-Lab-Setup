## 💻 Practical Commands

<details>
<summary><b>🔹 01. Network Interface Information</b></summary>

```bash
ifconfig
```

**Purpose:** To view network interfaces and their IP configurations.

</details>

<details>
<summary><b>🔹 02. Network Connectivity Testing</b></summary>

```bash
ping -c 4 google.com
```

**Purpose:** To test connectivity to Google's server.

**Observation:** The test reported 100% packet loss.

</details>

<details>
<summary><b>🔹 03. DNS Configuration</b></summary>

```bash
cat /etc/resolv.conf
```

**Purpose:** To view the DNS resolver configuration.

</details>

<details>
<summary><b>🔹 04. NetworkManager Configuration</b></summary>

```bash
# Generated by NetworkManager
search localdomain
```

**Purpose:** To understand the DNS configuration generated by NetworkManager.

</details>
